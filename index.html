● v1.1 · Phase 1 live

A documented contract for designers and engineers. Tokens, type, density, i18n, voice, and components — accessibility-first, additive on top of v1.

Eight deliverables shipping additively. The first three are stable; the rest are gated.

For designers

Browse Foundations to copy color, type, and spacing tokens into Figma. Browse Components for live previews and anatomy. Voice & tone is the language contract every UI string passes through review against.

Docs›Voice›Voice rules

Voice rules

● Stable

aiRA is a warm, neutral, precise, polite corporate colleague. Lead with the answer. Confirm completion. Refuse without apology.

10 hard rules

  1. Lead with the answer or the action. Confirm completion before elaborating.
  2. No exclamation marks except for confirmation: "Done."
  3. No emojis by default.
  4. No apologetic openers — never "Sorry, but…".
  5. Refusals follow the can't / can / next grammar.
  6. Hedge with evidence, not ego.
  7. Errors own the issue. Never blame the user.
  8. Greetings stay short. No mascot energy.
  9. aiRA never signs off.
  10. Sentence case for UI strings.

Do / don't

Don't

"Sorry, I'm not able to do that."

Do

"I can't run live exports without an approver. I can stage one. Would you like me to?"

Don't

"Oops! Something went wrong."

Do

"The export didn't finish. Snowflake dropped after 4 min. Retrying once."

Don't

"Hey there! 👋 Welcome to aiRA!"

Do

"Pick a campaign to start, or share what you'd like to build."

09 · Accessibility

Hard rules

Label adjacencyEvery series has a label adjacent to its visual mark. Color is never the only carrier.
ContrastBars and lines pass 3:1 against the surface they sit on. Verified for --cat-* and --viz-* in light + dark.
TooltipsHover surfaces exact value. Body uses --bg-overlay + --text-primary. Keyboard-accessible via focus.
Semantic tables<table>, <thead>, <tbody>. Sortable columns get aria-sort.
Chart fallbackEvery chart ships with an SR-only <table> immediately following the SVG.
Tabular numeralsfont-feature-settings: "tnum" on every numeric cell and chart label for clean column alignment.
Delta semanticsNegative deltas are orange (--delta-negative), not red. Red is reserved for errors and destructive actions.

Accessibility

  • Headline is an <h1> in the email DOM. One per email.
  • CTA link has descriptive text — never "click here".
  • Body text holds 4.5:1 contrast (slate-700 on white = 9.6:1).
  • Images carry alt. Decorative imagery uses alt="".
  • Plain-text fallback shipped alongside HTML for screen-reader-only clients.
  • lang attribute set on the root <html> per recipient locale.

Motion

● In review

Three durations, one curve. Motion is functional — it confirms an action or surfaces a state change. Decorative animation lives only on aiRA-generated content (sparkle, voice orb).

Duration tokens

TokenValueUseDemo
--motion-fast120 msHover · pressed · token swaps

All three share the curve cubic-bezier(0.4, 0, 0.2, 1).

Reduced motion

Wrap every animation in @media (prefers-reduced-motion: no-preference). Skeleton pulses, sparkle rotation, and voice-orb breathing all stop when the user opts out.

Docs›i18n›Bidi & numbers

Bidi & numbers

● Stable

Mixed-script content (an Arabic message that names Bukl or $12,408) is wrapped in Unicode bidi isolates via the <Bdi> component. Numerals, dates, currency all flow through Intl — never hand-rolled.

Mixed content in RTL

تم حفظ الجمهور 'Diwali repeat buyers · 12,408' بنجاح.
الإيرادات: $12,408.50 · النطاق: 2026-03-12
Brand names, currency, and dates are wrapped in <bdi> so the bidi algorithm treats them as opaque LTR runs inside the surrounding RTL flow.

Auto-isolation

Auto-applied for: brand names, model names, product names, currency, code spans, URLs, phone numbers, email addresses.

TypeRenders asExample

Rule: Eastern Arabic digits (٠١٢٣) are not used in any aiRA surface. Numerals are forced to Western (0123) via the -u-nu-latn Unicode extension on Intl.NumberFormat. B2B clarity > tradition.

An empty state is the first impression of a feature. Centered icon · plain copy · secondary action. Never an error tone — empty isn't broken.

Anatomy

Loading & streaming

● Stable

Name the work. "Searching the web…" not "Loading…". Skeletons preserve the bounding box. Streaming pills sit in the chat surface, never above it.

Streaming pill

Searching the web… Reading 4 files… Thinking…

Skeleton

Animated pulse --bg-surface-alt ↔ --bg-hover. Mirrors the bounding box of the content it's loading. aria-busy="true" on the container.

Streaming pill rules

Max length32 characters · named tool + ellipsis · no period
"Thinking…"Pre-first-token reasoning. Replaced by tool-running pill if a tool fires.
Generic "Loading…"Forbidden. Always name the work.
Pause"Paused. Tap continue when you're ready."
Docs›Patterns›Error handling

Error handling

● Stable

Errors own the issue. Never blame the user. Follow the what / why / next grammar — name what didn't work, the cause if known, and what happens next.

Error grammar

whatThe export didn't finish.
whyThe connection to Snowflake dropped after 4 minutes.
nextI'll retry once — say stop if you'd rather not.

Inline error (form field)

That CSV is missing a loyalty_id column. Add it and I can resume.

Toast error

Couldn't reach Snowflake. Retrying in 30s.

Forbidden openings

Don'tDo
"Sorry, something went wrong.""The export didn't finish. Snowflake dropped after 4 min."
"Oops!"(name the thing that broke)
"You forgot to…""That CSV is missing a loyalty_id column."
"Try again later.""I'll retry once — say stop if you'd rather not."

Hard rules

Density floorHit area ≥ 44 px in compact + standard, ≥ 48 px in comfortable. Never below 44.
Color is not the only carrierEvery series in a chart has a label adjacent to its visual mark.
Chart fallbackEvery chart ships with an SR-only <table> immediately following the SVG.
Keyboard parityTooltips, dropdowns, popovers all reachable + dismissible via keyboard.
Reduced motionAnimations gated by @media (prefers-reduced-motion: no-preference).
Forbidden colors for actionNegative deltas use orange (--delta-negative), not red. Red is reserved for errors and destructive actions.

Contributing

● Phase 1 · Deliverable 7 — planned

A formal Component Contribution RFC template lands in Phase 1, Deliverable 7. Until then, follow these review rules.

How to add a new component

  1. Open an issue describing the component, its prop API, and the existing patterns it relates to.
  2. Add Tier 3 tokens for the component to tokens/component.json. Components never reference Tier 1 directly.
  3. Build the component consuming Tier 3 → Tier 2 → Tier 1.
  4. Add a Preview / Code / Spec page to this docs site.
  5. Document voice — every UI string must pass the voice contract.
  6. Add SR-only fallbacks for any non-text content.
  7. Verify in light + dark, LTR + RTL, all three densities.

Review rules

CheckRequired
Logical CSS only (no padding-left, no hard-coded left/right)✓
Hit area ≥ 44 px even when visible chrome is smaller✓
Focus visible on every interactive element✓
Token reference (no raw hex in component CSS)✓
Voice rules — no apologetic openers, sentence case, no goodbye✓
Reduced motion gate on every animation✓
Bidi isolation for brand names, currency, code spans✓

/* Then consume tokens */

  border-radius: var(--radius-md);

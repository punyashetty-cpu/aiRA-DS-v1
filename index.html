aiRA Design System

Accessibility-first, WCAG AA+, light + dark parity, built on Roboto with a 4px base grid. Two-tier semantic token architecture. Mirror Figma library: aiRA Design System v1.1.

This file is fully self-contained. Save it locally and it will render anywhere — no external CSS, no external fonts (Roboto falls back to system sans), no build step. Toggle Light/Dark and LTR/RTL via the top bar.

Bidi & numbers

Mixed-script content (an Arabic message that names Bukl or $12,408) is wrapped in Unicode bidi isolates via the <Bdi> component. Numerals, dates, currency all flow through Intl — never hand-rolled.

Mixed content in RTL

تم حفظ الجمهور 'Diwali repeat buyers · 12,408' بنجاح.
الإيرادات: $12,408.50 · النطاق: 2026-03-12
Brand names, currency, and dates wrap in <bdi> so the bidi algorithm treats them as opaque LTR runs inside the surrounding RTL flow.

Auto-isolation

TypeRenders asExample
Brand<Bdi>Bukl · aiRA
Currency<Bdi numeric>₹2,55,00,000 · $12,408.50
DateIntl.DateTimeFormat12 Mar 2026 · 2026年3月12日
Relative timeIntl.RelativeTimeFormatyesterday · أمس · 昨日
Rule: Eastern Arabic digits (٠١٢٣) are not used in any aiRA surface. Numerals force Western (0123) via the -u-nu-latn Unicode extension on Intl.NumberFormat. B2B clarity > tradition.

Voice rules

aiRA is a warm, neutral, precise, polite corporate colleague. Lead with the answer. Confirm completion. Refuse without apology.

10 hard rules

  1. Lead with the answer or the action. Confirm completion before elaborating.
  2. No exclamation marks except for confirmation: "Done."
  3. No emojis by default.
  4. No apologetic openers — never "Sorry, but…".
  5. Refusals follow the can't / can / next grammar.
  6. Hedge with evidence, not ego.
  7. Errors own the issue. Never blame the user.
  8. Greetings stay short. No mascot energy.
  9. aiRA never signs off.
  10. Sentence case for UI strings.

Don't

"Sorry, I'm not able to do that."

Do

Refusal grammar — can't / can / next

Three short clauses, in order. Every refusal in aiRA's surfaces follows this shape.

can'tI can't delete production audiences from here.
canI can flag the audience for the Ops queue with your reason.
nextWould you like me to flag it?
can'tI can't run that query on a live segment without approval.
canI can run it on the staging replica right now.
nextShall I switch over?

Hard rules

  • Hit area ≥ 44×44px on every touchable.
  • Focus visible on every interactive — no outline: none.
  • Status info conveyed by colour AND text/icon.
  • Reduced motion respected (prefers-reduced-motion: reduce) — this page already honours it.
  • Form fields have programmatic labels via for / id or aria-labelledby.
  • Errors associated via aria-describedby.

Install

Drop tokens.css into the document head and start consuming Tier 2 / Tier 3 custom properties. This file is the entire system in one HTML — save it locally for offline reference.

StepWhat
1 · TokensCopy this file's CSS (everything inside <style>) into tokens.css, or use this file as-is.
2 · Dark modeSet data-theme="dark" on the <html> element. All semantic tokens switch in lockstep.
3 · RTLSet dir="rtl" on the <html> element. Logical properties handle the rest.
4 · FigmaEnable "aiRA Design System v1.1" in Figma → Libraries. Components grouped by Web / Mobile / Charts.
